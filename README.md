# 📈 Bluestock Fintech Capstone Project

## 📌 Project Overview

This project is a comprehensive data analytics capstone focused on the Indian Mutual Fund industry. Using multiple datasets provided by Bluestock Fintech, the objective is to analyze fund performance, investor behavior, portfolio holdings, assets under management (AUM), and benchmark indices to generate meaningful business insights.

The project follows an end-to-end data analytics workflow, including data cleaning, exploratory data analysis (EDA), visualization, and dashboard creation to support data-driven investment decisions.

---

# 🎯 Objectives

- Analyze mutual fund performance across different schemes.
- Study Assets Under Management (AUM) trends.
- Understand investor transaction patterns.
- Compare benchmark index performance.
- Analyze portfolio holdings of mutual funds.
- Build interactive dashboards for visualization.
- Generate actionable business insights for investors and fund managers.

---

# 📂 Dataset

The project consists of multiple datasets:

| Dataset | Description |
|----------|-------------|
| `03_aum_by_fund_house.csv` | Assets Under Management (AUM) for different fund houses |
| `07_scheme_performance.csv` | Performance metrics of mutual fund schemes |
| `08_investor_transactions.csv` | Investor purchase and redemption transactions |
| `09_portfolio_holdings.csv` | Holdings of mutual fund portfolios |
| `10_benchmark_indices.csv` | Benchmark index performance data |
